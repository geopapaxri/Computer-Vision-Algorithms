This repository contains Python implementations of advanced digital image processing and computer vision algorithms. The project focuses on frequency-domain analysis, feature extraction, and depth estimation techniques.

Project Structure

-functions.py: Contains the core algorithmic implementations, including spatial/frequency filters, edge detectors, and disparity map calculations.

-demo.py: The main execution script that applies the algorithms to test images and visualizes the transformations and computer vision pipelines.

-report.pdf: A comprehensive technical document detailing the mathematical foundations, algorithm parameters, and an analysis of the visual results.

Key Implementations

-Frequency-Domain Filtering: Application of 2D Discrete Fourier Transforms (DFT) for spatial frequency analysis and image filtering.

-Feature Extraction: Implementation of Harris corner detection and extraction of local descriptors for image analysis.

-Stereo Vision: Engineering of depth mapping algorithms to calculate accurate disparity maps from stereoscopic image pairs.

Technologies Used

1)Python

2)NumPy (Matrix operations and transformations)

3)PIL / OpenCV (Image handling)

4)Matplotlib (Data and image visualization)
